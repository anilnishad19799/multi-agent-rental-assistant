☁️ LangSmith Cloud Integration Guide

Every multi-agent run in this application is instrumented with native LangSmith tracing. You can view traces in both this local dashboard and in the official LangSmith Cloud simultaneously!

1. Enable Cloud Tracing in .env

# Enable official LangSmith Cloud Tracing
LANGCHAIN_TRACING_V2=true
LANGCHAIN_API_KEY=lsv2_pt_your_langsmith_api_key_here
LANGCHAIN_PROJECT=real-estate-rental-agent
LANGCHAIN_ENDPOINT=https://api.smith.langchain.com

2. Restart the Backend

Restart your server. Every chat turn will immediately stream to your LangSmith project dashboard at smith.langchain.com!

3. Direct Cloud Dashboard Access

Once your API key is configured, click the "Open LangSmith Cloud ↗" button in the top bar to inspect cloud traces with LangSmith latency graphs, token counters, and dataset evaluation.
